# Бот "Экспресс-диагностика по математике"

Самый быстрый путь для человека без опыта в программировании — задеплоить
на **Railway.app**. Всё делается через браузер, без установки чего-либо
на компьютер. Займёт 20–30 минут.

## Шаг 1. Создать бота в Telegram
1. Напиши в Telegram боту **@BotFather** команду `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`, например `mathdiag_bot`).
3. BotFather пришлёт **токен** вида `123456:ABC-...` — сохрани его, это `BOT_TOKEN`.

## Шаг 2. Создать чат для отчётов
1. Создай в Telegram новую **группу** (или канал) — например "Диагностика — отчёты".
2. Добавь туда своего бота и сделай его **администратором**.
3. Чтобы узнать `REPORT_CHAT_ID`:
   - добавь в эту же группу бота **@getidsbot** — он пришлёт id группы (число вида `-1001234567890`);
   - удали @getidsbot из группы, он больше не нужен.

## Шаг 3. Загрузить код на GitHub
1. Зарегистрируйся на github.com (если ещё нет аккаунта).
2. Создай новый репозиторий, например `math-diag-bot`.
3. Загрузи туда все файлы из этой папки (`bot.py`, `requirements.txt`,
   `Procfile`) через кнопку **"Add file → Upload files"** прямо в браузере —
   командная строка не нужна.

## Шаг 4. Задеплоить на Railway
1. Зайди на railway.app, зарегистрируйся через GitHub.
2. **New Project → Deploy from GitHub repo** → выбери свой репозиторий.
3. Railway сам определит Python-проект и установит зависимости.
4. Зайди в **Variables** и добавь:
   - `BOT_TOKEN` — токен из шага 1
   - `REPORT_CHAT_ID` — id из шага 2
   - (опционально) `SIGNUP_URL` — ссылка на запись/твой Telegram
   - (опционально) `CONTACT_USERNAME` — твой @username
5. Убедись, что команда запуска — `python bot.py` (Railway обычно берёт
   её из `Procfile` автоматически).
6. Нажми **Deploy**. Через минуту бот в Telegram оживёт — напиши ему `/start`.

Бот работает через long polling (без вебхуков), поэтому дополнительных
настроек домена/HTTPS не требуется.

## Как вставить свои задания
Открой `bot.py`, найди списки `TASKS_OGE` и `TASKS_EGE` в начале файла.
Каждое задание — это:

```python
Task("Тема задания", "Текст вопроса", "правильный_ответ")
```

- **Тема** используется только для формирования персональной рекомендации
  ("стоит повторить: ...") — пиши коротко и понятно ученику.
- **Ответ** сравнивается как текст после нормализации (пробелы убираются,
  запятая → точка, регистр не важен). Для ОГЭ/ЕГЭ части 1 этого достаточно,
  так как там короткие числовые ответы.
- Если в задании нужна картинка (график, чертёж) — положи файл в папку
  `images/` рядом с `bot.py` и укажи `image="images/имя_файла.png"`.

После правки — просто загрузи обновлённый `bot.py` в GitHub-репозиторий,
Railway передеплоит бота автоматически.

## Что бот делает автоматически
- Ведёт ученика по сценарию: приветствие → выбор экзамена → имя → класс →
  10 заданий → результат → персональная рекомендация → призыв к записи.
- Кнопка "Не знаю / пропустить" на каждом задании — не блокирует прохождение.
- В конце присылает тебе в отдельный чат: имя, класс, экзамен, баллы и
  список слабых тем — по каждому ученику отдельным сообщением.

## Проверить локально (по желанию)
```
pip install -r requirements.txt
cp .env.example .env   # и вписать туда свои значения
python bot.py
```
